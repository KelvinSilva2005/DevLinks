# DevLinks

![preview](.github/preview.jpg)

## 💡 Projeto

DevLinks é um agregador de links responsivo e com troca de tema (dark/light mode), que você pode usar como cartão de visitas nas suas redes sociais. Este projeto foi desenvolvido durante o curso Discover, da Rocketseat.

## 🚀 Tecnologias

Este projeto foi desenvolvido utilizando:

- HTML
- CSS
- JavaScript
- Git e GitHub
- Figma

## 🎨 Layout

Você pode visualizar o layout do projeto através [deste link](https://www.figma.com/design/0CY4VlU5Gcpzp98FTibZ9F/DevLinks-%E2%80%A2-Projeto-Discover--Community-).

## 📖 O que aprendi

- Fundamentos de HTML e CSS (box model, flexbox, position)
- Variáveis CSS para implementar dark/light mode
- Fundamentos de JavaScript (variáveis, condicionais, DOM)
- Controle de versão com Git e GitHub
